# Where a Follow Up Boss escalation goes

An escalation is internal. The lead is not emailed and not texted.

The event is created on the Fahad Javed booking calendar, and it is also added to these calendars:

- sales@fahadsold.com
- fahad@fahadsold.com

A notice email goes to:

- info@fahadsold.com
- fahad@fahadsold.com
- sales@fahadsold.com
- info@preconfactory.com

A text goes to:

- (647) 898-1739
- (416) 829-6121
- (416) 399-4289

If the call is 15 minutes or more away, those same three numbers get another text 2 minutes before the call. A call set for 5 minutes does not get that second text.

An escalation does not create a booking and does not create a Follow Up Boss appointment, so it does not show on the Follow Up Boss appointment list.
